# 柠檬账 · 使用说明

这是一个部署在自己电脑上的财务记账系统。整个文件夹拷过去就能用，**不需要安装数据库、不需要联网**。

---

## 零、先看这一点：你的电脑是 Windows 7 吗？

系统分两种角色，**服务端不能跑在 Windows 7 上**（内置数据库不支持），但 Windows 7 可以正常**使用**：

| 你的情况 | 该用哪个包 |
| --- | --- |
| Windows 10 / 11，自己这台电脑既当服务器又自己记账 | 本包（`lemon-win-x64-*.zip`），双击 1 号或 2 号图标 |
| Windows 7，只用浏览器记账，服务器在别的电脑或 NAS 上 | **客户端包**（`lemon-client-*.zip`），见下 |

**Windows 7 用户请这样做**：

1. 解压客户端包，用记事本打开 `server.ini`，把 `url=` 改成服务器地址（例如 `http://192.168.1.100:8080`），保存
2. 双击 `1-打开柠檬账.bat`

客户端包自带一个浏览器（Firefox ESR 115，微软 IE 打不开本系统），**不需要安装任何软件，也不需要管理员权限**。详细说明见包内 `使用说明.txt`。

---

## 一、放在哪里

把整个文件夹解压到本机硬盘，推荐 `C:\lemon`。

**路径里不能有中文**（文件夹名和它的上级目录都不能），空格可以。原因是内置的数据库程序不支持中文目录，放在中文路径下会直接启动失败。如果启动时提示"安装路径包含中文"，按提示把文件夹移到 `C:\lemon` 即可。

**也不要放在这些位置**，否则数据库无法启动或容易损坏：

- 网络共享目录、映射的网络驱动器
- U 盘、移动硬盘
- OneDrive、坚果云等同步盘（同步过程会锁住数据库文件）

---

## 二、两个入口，什么时候用哪个

| 图标 | 用途 | 谁能访问 |
| --- | --- | --- |
| **1-离线单机运行.bat** | 自己试功能、看界面、核对数据 | 只有本机能打开（`127.0.0.1:18080`） |
| **2-正式使用.bat** | 正式记账，公司同事一起用 | 局域网内其他电脑也能打开（`http://本机IP:8080`） |

两者是**完全独立的两套数据**：单机版里的账套不会出现在正式版里，互不干扰，可以同时开着。

第一次使用建议先用「1-离线单机运行」熟悉一下，再切到「2-正式使用」建正式账套。

---

## 三、第一次启动

1. 双击 **2-正式使用.bat**
2. 第一次会自动初始化数据库，屏幕提示「首次初始化数据库，约 10–60 秒」，**不要关窗口**
3. 初始化完成后窗口会列出访问地址，浏览器自动打开
4. 页面会提示「首次使用，请创建系统管理员」，设置账号密码（密码至少 6 位）
5. 用这个账号登录后，点「新建账套」，选择会计准则（小企业会计准则 / 政府会计制度），设置启用年月
6. 账套建好后，先录入期初余额，再开始录凭证

> 忘了截图也没关系：任何时候重新双击图标，它会直接打开登录页，数据都还在。

## 四、日常使用

- **窗口不要关**：那个黑色窗口就是服务本体，关掉服务就停了。可以最小化。
- **停止服务**：双击 **3-停止运行.bat**，或者在那个窗口里按 `Ctrl+C`。
- **同事要访问**：双击 2 号图标后，窗口里会显示「局域网访问 http://192.168.x.x:8080」，把这一行发给同事即可。第一次启动时如果弹出「Windows 防火墙」提示，请点**允许访问**。
- **备份数据**：双击 **4-立即备份.bat**，备份文件生成在 `backups\prod\` 目录。建议每周把整个 `backups` 文件夹复制一份到 NAS 或网盘。

---

## 五、数据在哪里

| 内容 | 位置 |
| --- | --- |
| 数据库文件 | `data\prod\pg\`（正式）、`data\demo\pg\`（单机） |
| 运行日志 | `logs\prod\`、`logs\demo\` |
| 备份文件 | `backups\prod\` |
| 数据库口令 | `secrets\prod.pass`（不要删，删了旧数据就打不开了） |

**整个文件夹可以直接拷到另一台电脑继续用**（先停止服务再拷）。这是绿色部署的优点，也是风险：请务必定期备份。

## 六、遇到问题

| 现象 | 处理 |
| --- | --- |
| 双击后窗口一闪而过 | 说明启动失败。改双击 `scripts` 里的 `start.ps1` 不现实，请先看 `logs\prod\` 下最新的 `.log` 文件，或联系技术支持 |
| 提示端口被占用 | 8080 被别的程序占了（常见是 IIS、其他 Web 服务）。关掉占用程序，或按《运维手册》改端口 |
| 提示缺少 vcruntime140.dll | 安装包内 `pgsql\vcredist\VC_Redist.x64.exe`，装完重试 |
| 本机能开、同事打不开 | 看《运维手册》的「局域网访问排查」三步 |
| 数据看起来不对 | 先确认你打开的是哪个入口（单机版和正式版是两套数据） |

更详细的问题排查见同目录 **运维手册.md**。
