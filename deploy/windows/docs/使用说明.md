# 阳和财务系统 · 使用说明

这是一个部署在自己电脑上的财务记账系统。整个文件夹拷过去就能用，**不需要安装数据库、不需要联网**。

> **这份文档只讲「怎么把程序跑起来」。**
> 程序起来之后怎么记账、怎么审核、怎么结转出报表，看同目录 **《使用手册》**；
> 如果是 IT 要在服务器或 NAS 上部署给全单位用，看 **《部署手册-NAS》**。

---

## 零、先看这一点：你的电脑是 Windows 7 吗？

系统分两种角色，**服务端不能跑在 Windows 7 上**（内置数据库不支持），但 Windows 7 可以正常**使用**：

| 你的情况 | 该用哪个包 |
| --- | --- |
| Windows 10 / 11，自己这台电脑既当服务器又自己记账 | 本包（`yanghe-finance-win-x64-*.zip`），双击 **阳和财务系统** 图标 |
| Windows 7，只用浏览器记账，服务器在别的电脑或 NAS 上 | **客户端包**（`yanghe-finance-client-*.zip`），见下 |

**Windows 7 用户请这样做**：

1. 解压客户端包，用记事本打开 `server.ini`，把 `url=` 改成服务器地址（例如 `http://192.168.1.100:8080`），保存
2. 双击 `1-打开阳和财务系统.bat`

客户端包自带一个浏览器（Firefox ESR 115，微软 IE 打不开本系统），**不需要安装任何软件，也不需要管理员权限**。详细说明见包内 `使用说明.txt`。

## 一、放在哪里

把整个文件夹解压到本机硬盘，推荐 `C:\yanghe-finance`。

**路径里不能有中文**（文件夹名和它的上级目录都不能），空格可以。原因是内置的数据库程序不支持中文目录，放在中文路径下会直接启动失败。如果启动时提示"安装路径包含中文"，按提示把文件夹移到 `C:\yanghe-finance` 即可。

**也不要放在这些位置**，否则数据库无法启动或容易损坏：

- 网络共享目录、映射的网络驱动器
- U 盘、移动硬盘
- OneDrive、坚果云等同步盘（同步过程会锁住数据库文件）

---

## 二、怎么打开

双击文件夹里的 **阳和财务系统** 图标（文件类型是「HTML 应用程序」）。

它会先显示一个启动页，然后自动完成这些事：

1. 后台启动服务（首次会初始化数据库，约 10–60 秒）
2. 就绪后自动用默认浏览器打开记账界面
3. 启动页上会显示状态，并提供「打开阳和财务系统」「停止服务」按钮

**服务本体是任务栏里一个最小化的窗口**（标题是「阳和财务系统 · 正式使用」）。它负责跑数据库和后台服务：

- 可以点开看日志，或最小化放着不用管
- **关闭这个窗口就等于停止服务**，正在使用的人会连不上
- 想正式停止，用启动页上的「停止服务」按钮，或 `工具\3-停止运行.bat`

> 启动页关掉没关系，服务还在运行。要重新进入系统，双击图标即可（服务已在运行时秒开，不会重复启动）。

### 单机体验

启动页底部有「单机体验（仅本机，端口 18080）」链接。它和正式账套是**完全独立的两套数据**，用来试功能、核对数据，不会影响正式账。两者可以同时开着。

---

## 三、第一次启动

1. 双击 **阳和财务系统** 图标
2. 等待初始化（约 10–60 秒，启动页上有提示，**不要在这个阶段关掉任务栏里的服务窗口**）
3. 浏览器自动打开后，页面会提示「首次使用，请创建系统管理员」，设置账号密码（密码至少 6 位）
4. 用这个账号登录，点「新建账套」，会计准则选「政府会计制度（行政事业单位）」，设置启用年月
5. 账套建好后，先录入期初余额，再开始录凭证

> 以后任何时候双击图标，都会直接进入登录页，数据都还在。

## 四、日常使用

- **同事要访问**：双击图标启动后，服务窗口里会显示「局域网访问 http://192.168.x.x:8080」，把这一行发给同事即可。第一次启动如果弹出「Windows 防火墙」提示，请点**允许访问**。
- **备份数据**：双击 `工具\4-立即备份.bat`，备份文件生成在 `backups\prod\` 目录。建议每周把整个 `backups` 文件夹复制一份到 NAS 或网盘。
- **停止服务**：启动页的「停止服务」按钮，或 `工具\3-停止运行.bat`。

### `工具` 文件夹是做什么的

启动页打不开时的备用入口，以及运维操作：

| 文件 | 用途 |
| --- | --- |
| `1-单机体验.bat` | 不开启动页，直接以单机模式启动 |
| `2-正式使用.bat` | 不开启动页，直接以正式模式启动（窗口会显示全部日志） |
| `3-停止运行.bat` | 停止应用与数据库 |
| `4-立即备份.bat` | 立即备份正式库 |

## 五、数据在哪里

| 内容 | 位置 |
| --- | --- |
| 数据库文件 | `data\prod\pg\`（正式）、`data\demo\pg\`（单机） |
| 运行日志 | `logs\prod\`、`logs\demo\` |
| 备份文件 | `backups\prod\` |
| 数据库口令 | `secrets\prod.pass`（不要删，删了旧数据就打不开了） |

**整个文件夹可以直接拷到另一台电脑继续用**（先停止服务再拷）。这是绿色部署的优点，也是风险：请务必定期备份。

## 六、遇到问题

| 现象 | 处理 |
| --- | --- |
| 双击图标没反应，或提示"无法调用系统组件" | 安全软件可能拦截了 HTML 应用程序。改用 `工具\2-正式使用.bat` 启动，并把安装目录加入杀毒软件白名单 |
| 启动页显示"服务没有启动成功"并带红色原因 | 按那几行字处理即可（常见是端口被占用或路径不对）。要更详细的日志，用 `工具\2-正式使用.bat` 启动，那个窗口不会自动关闭 |
| 启动页一直停在"正在启动服务"超过 1 分钟 | 点开任务栏里的服务窗口看报错；或看 `logs\prod\` 下最新的 `.log` |
| 提示端口被占用 | 8080 被别的程序占了（常见是 IIS、其他 Web 服务）。关掉占用程序，或按《运维手册》改端口 |
| 提示缺少 vcruntime140.dll | 安装包内 `pgsql\vcredist\VC_Redist.x64.exe`，装完重试 |
| 本机能开、同事打不开 | 看《运维手册》的「局域网访问排查」三步 |
| 数据看起来不对 | 先确认你打开的是哪个模式（单机体验和正式使用是两套数据） |

更详细的问题排查见同目录 **运维手册.md**。
