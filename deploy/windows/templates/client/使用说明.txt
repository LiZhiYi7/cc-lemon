阳和财务系统 · 客户端（Windows 7 / 10 / 11 通用）
================================================

一、这个包是做什么的
--------------------
这是给"使用电脑"用的客户端，里面自带一个浏览器，不用安装任何软件，
也不会修改系统设置。双击就能打开账套。

数据都保存在服务器上（NAS 或"正式使用"那台电脑），本机不存账套数据，
所以换一台电脑、重装系统都不会丢数据。

> 如果你用的是 Windows 7，系统自带的 IE 浏览器打不开阳和财务系统（现代网页
> 技术已不支持 IE）。这个包就是为此准备的，请用包里的浏览器打开。


二、第一次使用，只需改一行
--------------------------
1. 右键点击 server.ini → 打开方式 → 记事本
2. 找到这一行：

       url=http://192.168.1.100:8080

   把 192.168.1.100 换成服务器的实际地址，保存。

   - 服务器是 NAS：填 NAS 的局域网 IP
   - 服务器是"正式使用"那台电脑：在那台电脑双击 2-正式使用.bat 后，
     窗口里会显示"局域网访问 http://192.168.x.x:8080"，照抄即可

3. 双击「1-打开阳和财务系统.bat」

以后每次使用都直接双击这个文件，不用再改配置。


三、运行环境
------------
- Windows 7 SP1 / Windows 10 / Windows 11，64 位
- 不需要安装 .NET、不需要管理员权限、不需要联网（只要能连到服务器）
- 内置浏览器：Firefox ESR 115.45.0（官方中文版，支持 Windows 7 的最后一个版本）


四、常见问题
------------
1. 提示 server.ini not found 或 url is empty
   → 按第二节修改 server.ini，保存后再双击。

2. 浏览器能打开但显示"无法连接"
   → 服务器没开，或地址/端口填错，或本机和服务器不在同一个局域网。
   → 先在浏览器地址栏试一下 http://服务器IP:8080/healthz，正常应显示 ok。

3. 360 / 电脑管家等安全软件提示风险
   → 这是自带浏览器的正常提示，选择"信任"或"允许本次运行"，并把
     整个文件夹加入信任目录。

4. 双击后没有反应
   → 检查 firefox 文件夹是否被误删；重新解压整个压缩包即可。
   → 本包不需要安装，移动文件夹后快捷方式可能失效，重新双击 bat 即可。

5. 想在桌面放个图标
   → 右键「1-打开阳和财务系统.bat」→ 发送到 → 桌面快捷方式。


五、关于内置浏览器
------------------
内置的 Firefox ESR 115 由 Mozilla 提供，遵循 Mozilla Public License 2.0，
源码见 https://archive.mozilla.org/pub/firefox/releases/115.45.0esr/source/ 。
该版本是 Mozilla 最后一个支持 Windows 7 的长期支持版，不再自动更新，
仅用于访问本系统。
