# 第一部分 开始使用

## 1. 打开系统

系统跑在单位的服务器（或 NAS）上，用浏览器访问，不需要安装任何软件。

**浏览器要求**：Chrome、Edge、Firefox 的较新版本。**不要用 IE**（本系统基于 Vue 3，IE 打不开）。

**地址**由 IT 提供，形如：

```
http://192.168.1.100:8080
```

建议把这个地址加入浏览器收藏夹。手机连同一局域网也能打开，界面会自动适应屏幕。

## 2. 登录与账号

### 2.1 登录

打开地址后是登录页，输入**用户名**和**密码**，点「登录」。

### 2.2 第一次使用：创建系统管理员

如果数据库是全新的，登录页会提示：

> 首次使用，请创建系统管理员

此时填写三个字段：

| 字段 | 说明 |
| --- | --- |
| 用户名 | 登录用，建议英文，如 `admin` |
| 姓名 | 会显示在凭证的「制单人」上，填真实姓名 |
| 密码 | 至少 6 位，建议 12 位以上 |

点「创建管理员并登录」，直接进入系统。

> 这个账号是**系统管理员**，权限最大（能看所有账套、能管所有用户）。建议只用它做管理，日常记账另建账号。

### 2.3 修改密码

右上角点自己的名字 → 「修改密码」，输入原密码和新密码即可。

**忘记密码**：系统没有「找回密码」功能，请找管理员在「用户管理」里重置（见 17.4）。

### 2.4 退出

右上角用户名 → 「退出登录」。公用电脑用完请退出。

## 3. 界面认识

```
┌─────────────────────────────────────────────────────────┐
│ 阳和财务系统   单位名称 / 账套名称 ▾      [账簿]  张三 ▾  │  ← 顶栏
├──────────┬──────────────────────────────────────────────┤
│ 凭证     │                                              │
│  新增凭证│                                              │
│  凭证列表│                工作区                        │
│ 账簿     │                                              │
│  科目余额表                                             │
│  ...     │                                              │
│ 报表     │                                              │
│ 期末     │                                              │
│ 设置     │                                              │
└──────────┴──────────────────────────────────────────────┘
```

| 位置 | 作用 |
| --- | --- |
| 左上「账套名称」 | 点它回到**账套列表**，切换别的账套 |
| 顶栏「账簿」下拉 | 政府会计账套有「财务会计」和「预算会计」两本，切换看账。单账簿账套不显示 |
| 左侧菜单 | 凭证、账簿、报表、期末、设置 |
| 右上「用户名」 | 账套列表、用户管理（仅系统管理员）、修改密码、退出登录 |
| 菜单里没看到的项 | 说明你没有对应权限，找账套管理员分配 |

进入账套后的**首页**有四个区块：

- **本期概况**：当前期间、本期凭证数、未审核数、货币资金余额、结账前还有几件事没做
- **快捷入口**：新增凭证、凭证列表、科目余额表、明细账、辅助核算余额表、结转与结账
- **最近凭证**：本期最新的 6 张，点进去直接看
- **报表**：本账套全部报表的入口

## 4. 角色与权限

权限按账套分配，同一个人在不同账套可以是不同角色。

| 角色 | 能做什么 |
| --- | --- |
| **账套管理员** | 本账套全部操作，含账套设置、成员管理、删除账套 |
| **会计** | 科目、辅助核算、期初、凭证录入、平行记账规则、期末结转、结账 |
| **审核** | 审核与取消审核凭证，查看全部账表 |
| **查看** | 只能查看，不能修改任何东西 |

另外还有一个**系统管理员**身份（不是账套角色）：能进入所有账套、拥有全部权限，并能管理用户账号。

两条规则要记住：

1. **界面上看不到的按钮，就是你没权限**，不是系统出错。
2. 服务端也会校验权限，绕过界面直接调接口同样会被拒绝。

# 第二部分 会计日常

## 5. 一个月的完整流程

按下面顺序做，不会漏：

```
① 录入凭证  →  ② 审核凭证  →  ③ 期末结转  →  ④ 结账  →  ⑤ 出报表
   （会计）       （审核人）       （会计）        （会计）      （会计/领导）
```

| 步骤 | 在哪做 | 做到什么程度 |
| --- | --- | --- |
| ① 录入 | 凭证 → 新增凭证 | 本月业务全部录完，每张凭证借贷平衡 |
| ② 审核 | 凭证 → 凭证列表 → 勾选 → 审核 | 本月凭证状态都变成「已审核」 |
| ③ 结转 | 期末 → 结转与结账 → 一键结转 | 每张结转卡片都显示「已生成」 |
| ④ 结账 | 期末 → 结转与结账 → 结账 | 本期变成已结账，期间自动进入下个月 |
| ⑤ 报表 | 报表菜单 | 资产负债表校验通过，各表数字与账面一致 |

> 如果账套设置里开启了「结账前凭证须全部审核」，第②步不做完就无法结账。

## 6. 录入凭证

位置：**凭证 → 新增凭证**。

### 6.1 表头

| 字段 | 说明 |
| --- | --- |
| 凭证字 | 默认「记」，一般不用改 |
| 凭证号 | 自动取当前期间的下一个号，**可以手改** |
| 日期 | 决定凭证属于哪个期间。不能早于启用期间，也不能是已结账期间 |
| 附单据 | 附件张数，只作记录 |

### 6.2 分录

每行填三样：**摘要、会计科目、借方或贷方金额**。

- 科目框里可以输入**编码或名称**过滤，按**回车**选中第一项。
- 金额最多两位小数，可以填负数（红字）。
- 借方和贷方同一行只能填一个。

### 6.3 政府会计账套：左右两个区域

政府会计账套的凭证页分成左右两栏：**左边财务会计，右边预算会计**，一张屏幕内同时看到两套账簿。

```
┌──────────────────────┬──────────────────────┐
│ 财务会计             │ 预算会计             │
│ 摘要 | 科目 | 借 | 贷│ 摘要 | 科目 | 借 | 贷│
│ 支付办公费 | 5001 …  │ （生成后自动带出）   │
└──────────────────────┴──────────────────────┘
```

- **两栏各自借贷平衡**，互不干扰。
- 只涉及一个账簿的业务（例如计提折旧只记财务会计），只填一栏即可。
- 屏幕较窄（笔记本 1366 宽）时整页可以左右滚动；需要并排看全时按浏览器 `F11` 全屏，或把窗口拉宽。
- 打印时同样保持左右两栏，纸张方向自动按横向排版。

### 6.4 自动生成预算会计分录

录完财务会计分录后，点「**生成平行记账分录**」：

1. 只有财务会计分录里用到**现金类科目**（库存现金、银行存款、零余额账户用款额度、财政应返还额度、其他货币资金）时才会生成——即真正发生了纳入预算管理的现金收支。
2. 每条财务会计分录，按「平行记账规则」生成一条同方向、同金额的预算会计分录。
3. 生成结果可以手工修改；**需要资金性质的预算科目要手工选**（如事业支出）。
4. 有科目找不到规则时会给提示，需要手工补录。

**举例**：用银行存款支付办公费 1,000 元

| 账簿 | 分录 |
| --- | --- |
| 财务会计 | 借：业务活动费用 5001　1,000.00<br>贷：银行存款 1002　1,000.00 |
| 预算会计（自动生成） | 借：事业支出 7201　1,000.00<br>贷：资金结存—货币资金 800102　1,000.00 |

> **行政单位注意**：预置规则把支出对应到「事业支出 7201」。行政单位应改成「行政支出 7101」，改一次即可（设置 → 平行记账规则）。

### 6.5 辅助核算

如果科目启用了辅助核算（如事业支出启用「资金性质」），选中科目后，科目下方会出现项目选择框，**必须选择**，否则保存不了。

同一张凭证里已经选过的同类别项目，会自动带入下一行，减少重复选择。

### 6.6 图片附件（发票、回单）

凭证下方有一个「图片附件」区，用来放发票照片、银行回单、审批单截图。

**怎么加图**

- 点「选择图片」挑文件，或者直接把图片拖到附件区（拖动时边框会变蓝）。
- 支持 JPG / PNG / WebP，单张不超过 10MB，一张凭证最多 20 张。
- 点缩略图可以看大图，左右切换查看同一张凭证的全部图片。
- 鼠标移到缩略图右上角，点「×」删除。

**新凭证还没保存时**

可以先选图，缩略图上会标「待上传」，先存在本机浏览器里。点保存后系统会先存凭证、再自动把图片传上去，一路走完不需要额外操作。

如果上传失败（比如网络断了），会提示「凭证已保存，N 张图片未上传」。这时别关页面，点附件区右侧的「重试上传」即可补传。**没上传成功的图片只在你这台电脑上，刷新或换电脑就没了。**

**规则**

- **已审核的凭证不能增删图片**，需要先取消审核。
- 已结账期间的凭证同样不能改，包括图片。
- 图片不是「附单据张数」。表头的「附单据 ⋯ 张」是财务口径的张数记录，按你们单位的习惯填；图片区是实际存档的扫描件，两者互不影响。

**打印**

打印凭证时，图片会以小缩略图的形式跟着打印在分录下方。如果某类凭证不需要打印图片，上传前先不传即可；已上传的图片只能在凭证未审核、期间未结账时删除。

### 6.7 录入技巧

| 操作 | 效果 |
| --- | --- |
| 在金额格按 `=` | 自动填入让借贷平衡所需的金额 |
| 光标进入空的摘要格 | 自动带入上一行的摘要 |
| 光标进入最后一行 | 自动新增一行 |
| 按 `Ctrl+S` | 保存 |
| 点「保存并新增」 | 保存后清空内容，保留日期和凭证字，适合连续录入 |

### 6.8 保存时会检查什么

- 至少两行分录
- 每行都要有摘要、**末级且启用**的科目、借方或贷方金额之一
- **每个账簿内借贷必须平衡**
- 日期所在期间必须是启用期间之后、且未结账
- 启用了辅助核算的科目必须选齐项目
- 若账套开启了「平行记账完整性检查」，动了现金却没录预算分录会提示或禁止保存

保存后**立即生效**，账簿和报表马上能看到，没有「过账」这一步。

## 7. 查询与审核凭证

位置：**凭证 → 凭证列表**。

### 7.1 查询

顶部可按**期间范围**、**审核状态**、**摘要关键字**筛选，点「查询」。

列表里点凭证号可以打开凭证页。

### 7.2 审核

1. 勾选一条或多条凭证
2. 点「审核」

取消审核同理，勾选后点「取消审核」。

规则：

- **已审核的凭证不能修改、不能删除**，必须先取消审核。
- 如果账套设置里开启了「审核人不得为制单人」，那么自己做的凭证自己审不了，需要另一个人审。
- 只有「审核」权限的角色才能审核。

### 7.3 修改与删除

- 只能改**未审核**、且所在期间**未结账**的凭证。
- 删除后凭证号会出现断号，用「整理凭证号」修复。

### 7.4 整理凭证号

删除凭证后，某个期间的号会断开（如 记-1、记-3）。

1. 把筛选的起止期间设为**同一个期间**（只能对单期间整理）
2. 点「整理凭证号」

系统会把该期间的凭证按日期重新排成连续号（**按凭证字分别编号**）。

注意两点：**已审核的凭证也会被重新编号**，整理前请确认本月凭证已录完；**已结账的期间不能整理**。

## 8. 查账簿

左侧「账簿」菜单下有五张账。所有账簿都可以选期间范围、切换财务会计/预算会计、打印和导出 Excel。

| 账簿 | 看什么 |
| --- | --- |
| **科目余额表** | 各科目的期初余额、本期发生额、本年累计、期末余额。勾选「显示无数据科目」可看全部科目。点科目编码进入明细账 |
| **明细账** | 选一个科目，逐笔列出分录和余额，每月有「本期合计」「本年累计」。选上级科目会包含全部下级。点凭证字号可跳转到凭证 |
| **总账** | 一级科目逐月的期初、本期合计、本年累计 |
| **辅助核算余额表** | 选一个辅助核算类别（如资金性质），列出各项目在各科目的期初、本期发生、期末。可限定科目 |
| **辅助核算明细账** | 选一个项目，逐笔列出它涉及的分录和余额 |

**余额的显示规则**：按科目的余额方向列示，反方向余额显示为**负数**。例如负债类科目出现借方余额，显示为负数。

## 9. 期末结转与结账

位置：**期末 → 结转与结账**。画面分两部分：上面是结转规则卡片，下面是结账检查与结账按钮。

### 9.1 第一步：期末结转

每张卡片显示：这条规则本期是否适用、待结转金额是多少、是否已经生成过凭证。

两种做法：

- **一键结转**：按顺序执行本期所有适用的规则。**任何一步出错，整批都不生效**（不会留下半套凭证）。
- **逐条生成**：在具体卡片上点「生成凭证」，适合只想做其中一两项。

重要特性：

- **重复执行不会叠加**。再点一次会先删除该规则上次生成的凭证，再重新生成。
- 启用辅助核算的科目会**按项目逐一转平**。
- 结转生成的凭证带「系统生成」标记，可以在凭证列表里查到。

**本准则的结转规则**（政府会计制度）：

| 规则 | 时点 | 内容 |
| --- | --- | --- |
| 结转本期盈余 | 每月 | 财务会计的收入、费用 → 本期盈余 |
| 结转本年盈余分配 | 年末 | 本期盈余 → 本年盈余分配 |
| 结转累计盈余 | 年末 | 本年盈余分配、无偿调拨净资产、以前年度盈余调整 → 累计盈余 |
| 结转财政拨款收支 | 年末 | 财政拨款预算收入、财政拨款资金的支出 → 财政拨款结转 |
| 结转非财政专项资金收支 | 年末 | 非财政专项资金的收支 → 非财政拨款结转 |
| 结转经营收支 | 年末 | 经营预算收入、经营支出 → 经营结余 |
| 结转其他资金收支 | 年末 | 其余预算收支 → 其他结余 |
| 其他结余转入结余分配 | 年末 | 其他结余 → 非财政拨款结余分配 |
| 经营结余转入结余分配 | 年末 | 经营结余（仅盈余时）→ 非财政拨款结余分配 |
| 结余分配转入非财政拨款结余 | 年末 | 非财政拨款结余分配 → 非财政拨款结余 |

预算会计年末结转的两点注意：

- 预算收支按分录上的**资金性质**决定去向，没区分资金性质的科目一律按「其他资金」处理。
- **行政单位没有结余分配环节**：需要把「其他结余转入结余分配」的目标科目改为「非财政拨款结余」。
- 提取专用基金、财政拨款结转的内部明细冲销、结转转结余、上缴或注销等业务，需要**手工录凭证**，系统不自动做。

### 9.2 第二步：结账

结账前的检查项：

| 检查项 | 不通过时 |
| --- | --- |
| 只能结当前期间 | 不能结账 |
| 启用期间的期初必须试算平衡 | 不能结账 |
| 凭证借贷平衡 | 不能结账 |
| 必须执行的结转已完成 | 不能结账 |
| 凭证是否全部审核 | 仅提示（账套设置开启后变为不能结账） |
| 凭证号是否连续 | 仅提示 |

点「结账」后：

- 本期凭证**不能再新增、修改、删除**
- 当前期间自动进入下一个月

### 9.3 反结账

点「反结账」可以撤销最后一次结账。

**只能从最后一个已结账期间开始，逐期往回撤**，不能跳着撤。

## 10. 报表

位置：左侧「报表」菜单，子项由账套的报表模板生成。

选好期间即可查看，支持打印和导出 Excel。

| 报表 | 归属账簿 | 列 |
| --- | --- | --- |
| **资产负债表** | 财务会计 | 期末余额、年初余额 |
| **收入费用表** | 财务会计 | 本月数、本年累计数 |
| **预算收入支出表** | 预算会计 | 本月数、本年累计数 |
| **净资产变动表** | 财务会计 | 累计盈余、专用基金、权益法调整、净资产合计的年度变动 |
| **预算结转结余变动表** | 预算会计 | 年初、本年变动、年末 |

使用要点：

- 资产负债表上方提示「**校验未通过**」，通常是：本期损益/盈余还没结转，或者期初不平。先做结转再看。
- 收入费用表、预算收入支出表取的是**实际发生额**，不受结转凭证影响，结转前后数字一致。
- 净资产变动表、预算结转结余变动表**只有本年数**，没有「上年数」列。
- 净资产变动表里，直接记入累计盈余的调整，统一列在「归集调整预算结转结余」一行。
- 预算结转结余变动表的归集调入、上缴、调出等合并为一行净额；这张表要**年末结转做完**后，「年初 + 本年变动 = 年末」才成立。

## 11. 导入、导出与打印

### 11.1 导出 Excel

以下页面右上角有「导出 Excel」按钮，导出内容与页面显示一致（保留多行表头、合并单元格，金额是数值格式，可以直接计算）：

科目余额表、明细账、总账、辅助核算余额表、辅助核算明细账、全部报表、凭证列表

另外可导出档案：会计科目、辅助核算项目、期初余额（在对应设置页）。

### 11.2 导入

| 导入什么 | 位置 | 规则 |
| --- | --- | --- |
| 会计科目 | 设置 → 会计科目 → 导入 | 编码不存在则新增；已存在只更新名称。上级科目要已存在或在同一文件里 |
| 辅助核算项目 | 设置 → 辅助核算 → 导入 | 按当前选中的类别导入。编码不存在新增，已存在更新名称和备注 |
| 期初余额 | 设置 → 期初余额 → 导入 | 只导入末级科目。文件里出现的科目以文件为准，没出现的不变。启用辅助核算的科目每个项目一行 |

**步骤**：

1. 点「导入」→「下载模板」。模板里**已经包含当前数据**，直接在上面改或追加，别自己新建空表
2. 选填好的 `.xlsx`，系统显示读到的行数
3. 点「开始导入」

**整批生效**：只要有一行有问题，整个文件都不导入，并列出问题所在的 Excel 行号。改完重新选文件即可。

导入和手工录入遵循完全相同的规则（编码方案、末级科目、辅助核算必填、已结账不可改期初）。政府会计账套按**当前选中的账簿**导入，导预算会计就先切到预算会计。

### 11.3 打印

账簿、报表、凭证页都有「打印」按钮，调用浏览器打印，打印时自动隐藏菜单和按钮。

需要 PDF 时，在打印对话框里把「目标打印机」选成「另存为 PDF」。

# 第三部分 新账套开账

> 这一部分是**一次性**工作，做完才能开始记账。会计或账套管理员操作。

## 12. 建账套

位置：账套列表 → 右上角「新建账套」。

| 字段 | 说明 |
| --- | --- |
| 账套名称 | 自己看得懂的名字，如「2026 年单位账」 |
| 单位名称 | 会出现在报表抬头上，填全称 |
| 会计准则 | 当前只有「政府会计制度（行政事业单位）」 |
| 启用期间 | 从哪年哪月开始记账 |

**会计准则和启用期间建账后不能修改。** 填之前确认好。

建账时会按准则自动预置：科目表、辅助核算类别、凭证字、报表模板、期末结转规则、平行记账规则。这些复制进账套后各账套独立，可以各自调整。

建账的人自动成为该账套的**账套管理员**。

## 13. 会计科目

位置：**设置 → 会计科目**。按账簿、科目类别分页显示。

### 13.1 编码规则

- 编码方案默认 **4-2-2-2**，即一级 4 位、下级每级 2 位，最多 **4 级**
- 下级编码必须以上级编码开头，例如 `5001` → `500101`
- **只有末级科目可以记账**

### 13.2 常用操作

| 操作 | 说明 |
| --- | --- |
| 新增一级科目 | 编码自动建议为同级最大编码 +1 |
| 新增下级 | 在科目行上操作，编码同样自动建议 |
| 编辑 | 可改名称；**余额方向只有在该科目没有任何数据时才能改** |
| 停用 / 启用 | 停用的科目不能用于新凭证，历史数据不受影响 |
| 删除 | 只能删没有下级、没有凭证、没有期初的科目 |
| 现金类 | 标记库存现金、银行存款、零余额账户用款额度等。首页的「货币资金」和自动生成预算分录都依据它 |

> **给已有数据的科目增加第一个下级时**，该科目已有的期初和凭证数据会**自动转移到新增的下级科目**上。这是正常行为，不是数据丢失。

### 13.3 辅助核算的启用

在「编辑科目」里勾选辅助核算类别。规则：

- 只有末级科目能启用，可以同时启用多个类别
- 启用后，该科目的每条分录、每笔期初都必须为每个类别选一个项目
- **科目一旦有了凭证或期初数据，就不能再启用或调整辅助核算**——务必在开始记账前设置好
- 启用了辅助核算的科目**不能再增加下级**

## 14. 辅助核算

用「项目」代替明细科目来细分核算，例如费用按部门、应收按客户、预算支出按资金性质。

位置：**设置 → 辅助核算**。

- 预置类别：客户、供应商、职员、部门、项目、资金性质
- 可以新增自定义类别（如合同、车辆），也可以重命名
- 每个类别下维护项目：编码、名称、备注
- **已被凭证或期初用过的项目不能删除，只能停用**

> 政府会计账套里，事业预算收入、行政支出、事业支出等需要区分资金来源的预算科目，已默认启用「资金性质」。资金性质预置三项：财政拨款资金、非财政专项资金、其他资金。

## 15. 期初余额

位置：**设置 → 期初余额**。

### 15.1 填写规则

- 只在**末级科目**录入，上级科目自动汇总显示
- 按科目的余额方向填；反方向余额填**负数**
- **损益（收支）类科目没有期初余额**
- **年中启用**（启用月份不是 1 月）时，会多出「本年累计借方 / 贷方」两列，用来填年初到启用前的累计发生额；损益类科目的实际发生额填在这里
- 启用辅助核算的科目，点金额处的「按项目录入」，每个项目一行，科目期初等于各行之和

### 15.2 试算平衡

页面顶部实时显示每个账簿的试算平衡结果。政府会计账套的**财务会计和预算会计分别试算**，两个都要平。

### 15.3 什么时候会锁住

**启用期间结账之后，期初就不能再改了**。确需修改，先反结账。

# 第四部分 管理员

## 16. 账套设置与成员

位置：**设置 → 账套设置**（仅账套管理员可见）。

### 16.1 基本信息

可改：账套名称、单位名称、科目编码方案（如确需调整）。

不可改：会计准则、启用期间。

### 16.2 三个业务开关

| 开关 | 打开后的效果 | 建议 |
| --- | --- | --- |
| 审核人不得为制单人 | 自己做的凭证自己审不了 | 单人做账的小单位可以不打开；有两个人以上时建议打开 |
| 结账前凭证须全部审核 | 有未审核凭证就无法结账 | 要求严格内控时打开 |
| 平行记账完整性检查 | 不检查 / 保存时提示 / 缺少时禁止保存 | 建议保持「保存时提示」，先提示不阻断 |

### 16.3 成员与角色

同一页面下方是「成员与角色」：

- 添加成员：从已有用户里选一个人 + 选角色
- 修改角色：直接在表格里改下拉框
- 移除成员：把某人移出本账套（不影响他的账号）

规则：

- 每个账套**至少保留一名账套管理员**
- 用户必须先在「用户管理」里存在，才能被加进账套
- 一个人可以在多个账套里担任不同角色

### 16.4 删除账套

页面底部，需要**输入账套名称**确认。

**删除后数据无法恢复。** 删之前确认：这个人不需要了、备份里有近期数据、不是点错了账套。

## 17. 用户管理（系统管理员）

位置：右上角用户名 → **用户管理**。只有系统管理员能看到这一项。

### 17.1 新增用户

点「新增用户」，填用户名、姓名、初始密码，按需勾选「系统管理员」。

新建的用户**还没有任何账套权限**，需要到对应账套的「成员与角色」里添加。

### 17.2 停用与启用

离职或临时离岗的人，把「启用」关掉。停用后不能登录，但历史凭证上的姓名、操作日志都保留。

**不要用删账号的方式处理离职**，会破坏历史数据的可追溯性。

### 17.3 设为 / 取消系统管理员

在用户行上切换。系统管理员权限很大，建议只保留 1–2 个。

### 17.4 重置密码

用户忘记密码时，在用户行点「重置密码」，设一个新密码告诉他，让他登录后自己改。

### 17.5 权限怎么给才合理

一个常见的分工：

| 人 | 系统管理员 | 账套角色 |
| --- | --- | --- |
| 财务负责人 | 否 | 账套管理员 |
| 会计 | 否 | 会计 |
| 复核人 | 否 | 审核 |
| 单位领导 | 否 | 查看 |
| IT / 系统负责人 | 是 | 不加入账套 |

系统管理员不加入账套，可以避免「顺手改了一笔账」这类问题——他的权限在技术上覆盖所有账套，但界面上不主动出现在账套成员列表里，操作日志也能更清楚地反映谁在记账。

## 18. 数据安全与分工

### 18.1 系统做了什么

- **操作日志**：登录、凭证增删改审、结账与反结账、科目与规则变更、导入等，都记录操作人和时间（目前存在数据库中，没有查询界面）
- **服务端强制保护**：已结账期间、已审核凭证，绕过界面也无法修改
- **每日自动备份**：由部署时的备份容器完成，默认保留 30 天（详见《部署手册-NAS》第 7 章）

### 18.2 你要做的

| 事项 | 谁负责 | 频率 |
| --- | --- | --- |
| 确认备份文件在生成 | IT | 每月看一眼备份目录 |
| 把备份复制到另一台设备 | IT | 每周 |
| 离职人员停用账号 | 系统管理员 | 即时 |
| 检查成员与角色是否仍然合理 | 账套管理员 | 每半年 |
| 年末结账前手动备份一次 | 会计 + IT | 每年 |

### 18.3 关于浏览器与网络

- 系统面向**单位内部局域网**，默认不加密传输（HTTP）
- 不要用公共 Wi-Fi 或网吧电脑登录
- 需要从家里访问时，先连单位 VPN，再由 IT 配置 HTTPS，不要直接把端口开放到公网

# 附录 B 常见问题

### B.1 登录相关

**打开地址是空白页 / 一直转圈**
先按 `Ctrl+F5` 强制刷新。仍然空白就让 IT 检查服务是否在运行（他可以在服务器上执行 `curl http://127.0.0.1:8080/healthz`，返回 `ok` 才算正常）。

**密码错误 / 登录不了**
确认用户名不是姓名。连续失败仍不行，找管理员重置密码。

**提示账号已停用**
说明管理员把你的账号停用了，联系管理员。

### B.2 看不到功能

**左侧菜单少了某一项，或页面上没有按钮**
是权限问题。找账套管理员在「成员与角色」里确认你的角色。查看角色只有只读权限，看不到录入按钮是正常的。

**看不到「账套设置」**
只有账套管理员能看。找账套管理员改，或让他把你设为账套管理员。

### B.3 凭证相关

**科目选不到**
三个原因：① 该科目**不是末级**（有下级科目时不能直接记账）；② 科目**已停用**；③ 你切到了另一个账簿（预算会计的科目在财务会计里当然选不到）。

**保存时提示借贷不平**
政府会计账套要**分别**平衡：财务会计区和预算会计区各自平衡。常见原因是只改了其中一个区。

**凭证改不了 / 删不掉**
已审核的凭证要先取消审核；已结账期间的凭证要先反结账。

**凭证号断了**
用「整理凭证号」，注意只能对**单个期间**整理，且该期间凭证最好已经录完。

**动了银行存款，却没有自动生成预算分录**
检查：① 科目是否被标记为「现金类」；② 平行记账规则里该科目有没有对应规则；③ 金额是否为零。仍然没有就手工补录预算分录。

### B.4 期末与报表

**结转卡片显示待结转金额为 0**
说明该规则本期没有需要结转的余额，属正常。例如本月没有收入，就不会有结转本期盈余的金额。

**结账结不了**
按提示逐项处理。最常见的是：还有未完成的结转、有凭证借贷不平、启用期间期初不平。

**资产负债表提示「校验未通过」**
先做期末结转，再看是否平衡。仍然不平，通常是期初录入有问题，回到「期初余额」看试算平衡。

**报表数字和账簿对不上**
确认报表选的是同一个期间、同一个账簿（财务会计/预算会计），并注意报表取的是「实际发生额」还是「期末余额」。

### B.5 其他

**导出 Excel 后金额是文本，不能求和**
用系统内「导出 Excel」按钮导出的金额是数值格式。如果你是把页面内容复制到 Excel，会变成文本。

**打印出来有菜单和按钮**
请用页面上的「打印」按钮，不要用浏览器的 `Ctrl+P`。

**同事能打开、我打不开**
让 IT 检查你的电脑与服务器是否在同一网段、服务器防火墙是否放行端口。

# 附录 C 名词解释

| 名词 | 含义 |
| --- | --- |
| **账套** | 一套独立的账。一个单位可以有多套（如不同年度、不同主体），数据互不影响 |
| **账簿** | 账套内的核算维度。政府会计有「财务会计」和「预算会计」两本，即平行记账 |
| **平行记账** | 同一笔业务同时记财务会计和预算会计，两套账各自平衡 |
| **辅助核算** | 用「项目」代替明细科目来细分，如按部门、按客户、按资金性质 |
| **末级科目** | 没有下级科目的科目，只有它能记账 |
| **期初余额** | 开始用系统记账那一刻，各科目的余额 |
| **结转** | 期末把收入、费用（收支）类科目转到结余类科目，使收支类科目归零 |
| **结账** | 确认本期账务完成，锁定本期凭证，期间进入下个月 |
| **反结账** | 撤销最后一次结账，只能逐期往回撤 |
| **制单人 / 审核人** | 录入凭证的人 / 审核凭证的人，会显示在凭证上 |
| **试算平衡** | 所有科目借方合计等于贷方合计，是账务正确的基本前提 |
