## 1. 登录、用户与权限

**首次使用**：系统里还没有任何用户时，打开登录页会提示创建系统管理员。

**用户管理**（右上角用户名 → 用户管理，仅系统管理员）

- 新增用户、停用/启用、设为系统管理员、重置密码。
- 每个用户可在右上角“修改密码”自行改密码。密码至少 6 位。

**账套内的角色**（账套设置 → 成员与角色）

用户能进入哪些账套、能做什么，按账套分别分配：

| 角色 | 能做什么 |
| --- | --- |
| 账套管理员 | 全部操作，含账套设置、成员管理、删除账套 |
| 会计 | 科目、辅助核算、期初、凭证录入、平行记账规则、期末结转、结账 |
| 审核 | 审核与取消审核凭证，查看全部账表 |
| 查看 | 只能查看 |

- 建账的人自动成为该账套的账套管理员；每个账套至少保留一名账套管理员。
- 系统管理员可以进入所有账套并拥有全部权限。
- 没有写权限的角色，界面上不显示对应按钮，服务端也会拒绝。

## 2. 账套

**新建账套**（账套列表 → 新建账套）

填写账套名称、单位名称，选择会计准则和启用期间。**会计准则与启用期间建账后不能修改。**

内置两套准则：

| 准则 | 核算账簿 | 说明 |
| --- | --- | --- |
| 小企业会计准则 | 财务会计 | 单一账簿 |
| 政府会计制度（行政事业单位） | 财务会计 + 预算会计 | 平行记账；预置“资金性质”辅助核算和预算会计年末结转规则 |

建账时会按准则预置：科目表、辅助核算类别、凭证字、报表、期末结转规则、平行记账规则。这些内容复制进账套后各账套独立，可以分别调整。

**账套设置**（设置 → 账套设置，仅账套管理员）

- 修改账套名称、单位名称。
- 审核人不得为制单人（开关）。
- 结账前凭证须全部审核（开关）。
- 平行记账完整性检查：不检查 / 保存时提示 / 缺少时禁止保存（仅平行记账账套）。
- 成员与角色。
- 删除账套：需输入账套名称确认，**删除后数据无法恢复**。

**切换账套**：点击左上方账套名称回到账套列表。

## 3. 首页

进入账套后的默认页面：

- **本期概况**：当前期间、本期凭证数与未审核数、货币资金余额（现金类科目期末余额合计）、期末进度（还有几项结账前必须处理的事）。
- **快捷入口**：新增凭证、凭证列表、科目余额表、明细账、辅助核算余额表、结转与结账。
- **最近凭证**：本期最新的 6 张，点击进入。
- **报表**：本账套全部报表的入口。

## 4. 会计科目

位置：设置 → 会计科目。按核算账簿、科目类别分页显示。

**规则**

- 科目编码按编码方案（默认 4-2-2-2）逐级编排，下级编码以上级编码开头；最多 4 级。
- **只有末级科目可以记账。**
- 下级科目默认继承上级的类别、余额方向和“现金类”标记。

**操作**

- **新增一级科目 / 新增下级**：编码会自动建议为同级最大编码加 1。
- **给已有数据的科目增加第一个下级**：该科目已有的期初和凭证数据会自动转移到新增的下级科目上。
- **编辑**：可改名称；余额方向只有在科目没有任何数据时才能改。
- **停用 / 启用**：停用的科目不能再用于新凭证，历史数据不受影响。
- **删除**：只能删除没有下级、没有凭证和期初数据的科目。
- **现金类**：标记库存现金、银行存款等科目。首页的货币资金余额和平行记账的触发都依据它。
- **辅助核算**：见下一节。

## 5. 辅助核算

用“项目”代替明细科目来细分核算，例如应收账款按客户、费用按部门。

**档案**（设置 → 辅助核算）

- 预置类别：客户、供应商、职员、部门、项目；政府会计账套另有“资金性质”（财政拨款资金、非财政专项资金、其他资金）。
- 可以新增自定义类别（如合同、车辆）、重命名类别；自定义类别在没有项目且未被科目启用时可以删除。
- 每个类别下维护项目：编码、名称、备注。已被凭证或期初使用的项目不能删除，只能停用。

**在科目上启用**（设置 → 会计科目 → 编辑科目 → 勾选辅助核算类别）

- 只有末级科目可以启用，可同时启用多个类别。
- 启用后，该科目的每条分录、每笔期初都必须为每个类别选择一个项目。
- **科目已有凭证或期初数据后，不能再启用或调整辅助核算。** 请在开始记账前设置好。
- 启用辅助核算的科目不能再增加下级科目。

> 政府会计账套中，事业预算收入、行政支出、事业支出等需要区分资金来源的预算科目已默认启用“资金性质”。

## 6. 期初余额

位置：设置 → 期初余额。

- 只在末级科目录入，上级科目自动汇总显示。
- 余额按科目的余额方向填写，反方向余额填负数。
- **损益（收支）类科目没有期初余额。**
- **年中启用**（启用月份不是 1 月）时，多出“本年累计借方 / 贷方”两列，用于录入年初到启用前的累计发生额；损益类科目在这里录入实际发生额。
- **启用辅助核算的科目**：点击金额处的“按项目录入”，每个项目（或项目组合）一行；科目期初为各行之和。
- 页面顶部显示每个账簿的**试算平衡**结果。平行记账账套的财务会计和预算会计分别试算。
- 启用期间结账后，期初不能再修改（需先反结账）。

## 7. 凭证

### 录入（凭证 → 新增凭证）

- 凭证字、凭证号（自动取号，可手改）、日期、附单据张数。
- 每行：摘要、会计科目、借方金额或贷方金额。
- 科目选择框可输入编码或名称过滤，**回车选中第一项**。
- 科目启用了辅助核算时，科目下方出现项目选择框；本凭证其他分录已选过同类别项目的，会自动带入。

**录入便利**

| 操作 | 效果 |
| --- | --- |
| 在金额格按 `=` | 自动填入使借贷平衡的金额 |
| 光标进入空的摘要格 | 自动带入上一行摘要 |
| 光标进入最后一行 | 自动增加一行 |
| `Ctrl+S` | 保存 |
| 保存并新增 | 保存后清空，保留日期和凭证字，连续录入 |

**保存时的校验**

- 至少两行分录；每行必须有摘要、末级且启用的科目、借方或贷方之一。
- 金额最多两位小数；可以为负数（红字）。
- **每个核算账簿内借贷必须平衡。**
- 凭证日期所在期间不能早于启用期间，也不能是已结账期间。
- 启用辅助核算的科目必须选齐项目。

凭证保存后立即影响账簿和报表，没有单独的“过账”步骤。

### 凭证列表（凭证 → 凭证列表）

- 按期间范围、审核状态、摘要关键字查询。
- **审核 / 取消审核**：勾选后批量操作。已审核的凭证不能修改或删除，需先取消审核。
- **修改 / 删除**：仅限未审核、且所在期间未结账的凭证。
- **整理凭证号**：把某个期间的凭证按日期重新排成连续号（删除凭证产生断号后使用）。

### 凭证页

已保存的凭证可以审核、取消审核、删除、打印。由期末结转生成的凭证带有“系统生成”标记。

## 8. 平行记账

适用于政府会计制度账套：同一账套内财务会计和预算会计两套账簿并行。

**一张凭证、分区录入**

凭证页分为“财务会计”和“预算会计”两个区域，各自借贷平衡。只涉及一个账簿的业务（如计提折旧只记财务会计）只填一个区域即可。

**自动生成预算会计分录**

录完财务会计分录后点击“生成平行记账分录”：

1. 只有财务会计分录中出现**现金类科目**时才生成——即发生了纳入预算管理的现金收支。
2. 每条财务会计分录按规则生成一条同方向、同金额的预算会计分录。
3. 生成结果可以修改；需要资金性质的预算科目要手工选择。
4. 找不到规则的科目会给出提示，需要时手工补录。

**规则**（设置 → 平行记账规则）

- 每条规则：来源科目（财务会计）→ 目标科目（预算会计），可限定“仅借方发生”或“仅贷方发生”。
  例如短期借款贷方发生 → 债务预算收入，借方发生 → 债务还本支出。
- 规则对来源科目的下级同样生效；下级科目可另设规则覆盖。限定方向的规则优先。
- 可新增、编辑、删除。

> 预置规则把业务活动费用、单位管理费用对应到“事业支出”。**行政单位**请把目标改为“行政支出”。

**完整性检查**

财务会计分录动用了现金类科目、却没有录预算会计分录时，按账套设置：不检查、保存时提示（默认），或禁止保存。

## 9. 账簿

所有账簿都可以选择期间范围，支持打印和导出 Excel。平行记账账套可切换财务会计 / 预算会计。

| 账簿 | 内容 |
| --- | --- |
| **科目余额表** | 各科目的期初余额、本期发生额、本年累计发生额、期末余额。可选择显示无数据科目。点击科目编码进入明细账。 |
| **明细账** | 选择一个科目，逐笔列出分录和余额，每月有本期合计、本年累计。选择上级科目时包含全部下级。点击凭证字号进入凭证。 |
| **总账** | 一级科目逐月的期初余额、本期合计、本年累计。 |
| **辅助核算余额表** | 选择一个辅助核算类别，列出各项目在各科目的期初、本期发生和期末。可限定科目。点击科目进入辅助核算明细账。 |
| **辅助核算明细账** | 选择一个项目（可限定科目），逐笔列出分录和余额。 |

余额按科目的余额方向列示，反方向余额显示为负数。

## 10. 期末结转与结账

位置：期末 → 结转与结账。

### 第一步：期末结转

每条结转规则一张卡片，显示是否适用本期、待结转金额、已生成的凭证。

- **一键结转**：按顺序执行本期适用的全部规则。任何一步出错则全部不生效。
- 也可以逐条点击“生成凭证”。
- 重复执行会先删除该规则上次生成的凭证再重新生成，结果不会叠加。
- 启用辅助核算的科目按项目逐一转平。

**小企业会计准则**

| 规则 | 时间 | 内容 |
| --- | --- | --- |
| 结转损益 | 每月 | 全部损益类科目 → 本年利润 |
| 结转本年利润 | 年末 | 本年利润 → 利润分配—未分配利润 |

**政府会计制度**

| 规则 | 时间 | 内容 |
| --- | --- | --- |
| 结转本期盈余 | 每月 | 财务会计收入、费用 → 本期盈余 |
| 结转本年盈余分配 | 年末 | 本期盈余 → 本年盈余分配 |
| 结转累计盈余 | 年末 | 本年盈余分配、无偿调拨净资产、以前年度盈余调整 → 累计盈余 |
| 结转财政拨款收支 | 年末 | 财政拨款预算收入、财政拨款资金的支出 → 财政拨款结转 |
| 结转非财政专项资金收支 | 年末 | 非财政专项资金的收入与支出 → 非财政拨款结转 |
| 结转经营收支 | 年末 | 经营预算收入、经营支出 → 经营结余 |
| 结转其他资金收支 | 年末 | 其余全部预算收支 → 其他结余 |
| 其他结余转入结余分配 | 年末 | 其他结余 → 非财政拨款结余分配 |
| 经营结余转入结余分配 | 年末 | 经营结余（仅盈余时）→ 非财政拨款结余分配 |
| 结余分配转入非财政拨款结余 | 年末 | 非财政拨款结余分配 → 非财政拨款结余 |

预算会计年末结转的注意事项：

- 预算收入、支出按分录上的**资金性质**决定去向；没有区分资金性质的科目一律按其他资金处理。
- **行政单位**没有结余分配环节，需把“其他结余转入结余分配”的目标科目改为非财政拨款结余。
- 提取专用基金，以及财政拨款结转的内部明细冲销、结转转结余、上缴或注销等，需要手工录凭证。

### 第二步：结账检查与结账

| 检查项 | 不通过时 |
| --- | --- |
| 只能结账当前期间 | 不能结账 |
| 期初试算平衡（仅启用期间） | 不能结账 |
| 凭证借贷平衡 | 不能结账 |
| 必须执行的结转已完成 | 不能结账 |
| 凭证已全部审核 | 仅提示；账套设置中开启后变为不能结账 |
| 凭证号连续 | 仅提示 |

- **结账**后本期凭证不能新增、修改、删除，当前期间进入下一个月。
- **反结账**只能从最后一个已结账期间开始，逐期进行。

## 11. 报表

位置：报表菜单。选择期间即可查看，支持打印和导出 Excel。

**小企业会计准则**

- **资产负债表**：期末余额、年初余额。应收/预收、应付/预付等往来项目按明细科目余额方向重分类。
- **利润表**：本年累计金额、本月金额。

**政府会计制度**

- **资产负债表**（财务会计）：期末余额、年初余额。
- **收入费用表**（财务会计）：本月数、本年累计数。
- **预算收入支出表**（预算会计）：本月数、本年累计数。
- **净资产变动表**（财务会计）：累计盈余、专用基金、权益法调整、净资产合计四列的年度变动。
- **预算结转结余变动表**（预算会计）：年初、本年变动、年末，收支差额按资金性质拆分。

**使用说明**

- 资产负债表在页面上方提示“校验未通过”时，通常是本期损益尚未结转，或期初不平衡。
- 利润表、收入费用表、预算收入支出表取的是**实际发生额**，不受结转凭证影响，结转前后数字一致。
- 净资产变动表、预算结转结余变动表只有“本年数”，没有“上年数”。
- 净资产变动表中，直接记入累计盈余的调整全部列在“归集调整预算结转结余”一行。
- 预算结转结余变动表中，归集调入、上缴、调出等合并为一行净额；该表在年末结转完成后“年初 + 本年变动 = 年末”才成立。

## 12. Excel 导入导出与打印

### 导出

以下页面有“导出 Excel”按钮，导出内容与页面显示一致，金额为数值格式，保留多行表头和合并单元格：

科目余额表、明细账、总账、辅助核算余额表、辅助核算明细账、全部报表、凭证列表。

另外可导出档案：会计科目、辅助核算项目、期初余额。

### 导入

| 导入内容 | 位置 | 规则 |
| --- | --- | --- |
| 会计科目 | 设置 → 会计科目 → 导入 | 编码不存在的新增；已存在的只更新名称。上级科目须已存在或在同一文件里。新增科目可同时指定辅助核算。 |
| 辅助核算项目 | 设置 → 辅助核算 → 导入 | 按当前类别导入。编码不存在的新增；已存在的更新名称和备注。 |
| 期初余额 | 设置 → 期初余额 → 导入 | 只导入末级科目。文件中出现的科目以文件为准，未出现的不变。启用辅助核算的科目每个项目一行。 |

**导入步骤**

1. 在导入对话框点击“下载模板”。模板里已包含当前数据，直接在上面修改或追加即可；模板的第二张工作表是填写说明。
2. 选择填好的 `.xlsx` 文件，系统显示读取到的行数。
3. 点击“开始导入”。

**整批生效**：只要有一行有问题，整个文件都不会导入，并列出每个问题所在的 Excel 行号。修改后重新选择文件即可。

导入与手工录入遵循完全相同的规则（编码方案、末级科目、辅助核算必填、已结账不可改期初等）。平行记账账套按当前选中的账簿导入。

### 打印

账簿、报表、凭证页都有“打印”按钮，调用浏览器打印，打印时自动隐藏菜单和按钮。可在浏览器打印对话框中选择“另存为 PDF”。

## 13. 数据安全

- **操作日志**：登录、凭证增删改审、结账与反结账、科目与规则变更、导入等操作都会记录操作人和时间（目前只存在数据库中，没有查询界面）。
- **每日自动备份**：按 NAS 部署方式启动后，每天导出一次数据库，默认保留 30 天。恢复方法见 README。
- 已结账期间和已审核凭证在服务端强制保护，不能通过任何方式绕过界面修改。
- 系统面向可信的局域网，默认不加密传输。需要从外网访问时，应在前面加反向代理并启用 HTTPS。

- 现金流量表
